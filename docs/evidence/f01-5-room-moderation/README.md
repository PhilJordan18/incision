## Human recipe before closing #35

1. Host + second account + guest; open two tabs for a target and keep another peer.
2. Cancel once (target remains), then confirm expulsion: target tabs stop following,
   a clear message appears and the host/peer remain connected.
3. Retry by code and invitation with the same identity; both must refuse. A peer
   on the same network remains admitted. Try a spectator as well.
4. Repeat during a race and at results; completed results remain unchanged.
5. Transfer host through the existing succession flow; only the new host can act.
6. Repeat the important controls in FR/EN and light/dark themes.

Do not use the automated disposable database as Philippe's persistent recipe.
Prepare an additive migration on a verified clone of preserved recipe data only
after the delivery gates pass; never replace the original backup or reset 3880.
