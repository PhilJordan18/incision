# Application web Incision

Cette application Next.js appartient au workspace npm `@incision/web`. Depuis la racine du dépôt :

```sh
npm ci
npm run dev -w @incision/web
npm run lint -w @incision/web
npm run build -w @incision/web
```

Le contenu de la page d'accueil est encore celui du générateur Next.js. Les fonctions métier et le serveur temps réel viendront ensuite. Lire le [guide d'installation](../../docs/SETUP.md) et [l'architecture](../../docs/architecture/README.md) avant d'implémenter une feature.
